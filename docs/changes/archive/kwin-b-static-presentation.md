## Verification and remaining evidence

The ordinary gates are `npm --prefix kwin run typecheck`, `npm --prefix kwin test`, and the `native` job's Nix/CMake CTest build (`BUILD_TESTING=ON`; see the [KCM audit](kwin-b-static-kcm.md#verification)). Typecheck and all 15 focused bundled source-pin tests passed; whitespace checks passed and frozen fixtures were unchanged. No separate KWin lint/format script is defined. On `f3d9a4e5` the full npm suite ran 1,483 tests: 1,480 passed, one skipped, one failed, and one timed out. The exact float fallback placement failure in `world-producer-journeys.test.ts` also reproduced on clean `f3d9a4e5` (17/18 passed). The discovery byte-parity timeout did not recur when `world-bytes.test.ts` ran alone (6/6 passed with and without the audit changes).

The native CTest gate was not run on this workstation; no native, fixture-runner, or live acceptance is claimed. Reference-outcomes lines 6940, 6942 and 6943 still record incomplete native evidence, not a reversal of the freshness or focus decisions.
